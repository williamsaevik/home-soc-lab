![Wazuh Threat Hunting Dashboard](screenshots/02-wazuh-alerts.png)

## About the Project

This is a personal cybersecurity project where I built a small SOC lab to practice security monitoring and incident detection.

The goal is to gain hands-on experience with Linux, SIEM tools, and security investigations.

## Technologies Used

- **Fedora Linux** – Main operating system
- **Ubuntu Server** – Virtual machine
- **VMware Workstation** – Virtualization
- **Wazuh SIEM** – Security monitoring and log analysis
- **OpenSSH** – Remote access and authentication testing

## What I've Done

- Installed and configured Ubuntu Server and Wazuh.
- Connected to the server using SSH.
- Simulated failed SSH login attempts.
- Investigated authentication logs using `journalctl`.
- Detected suspicious login activity in Wazuh.
