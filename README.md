# Home SOC Lab

![Wazuh Threat Hunting Dashboard](screenshots/02-wazuh-alerts.png)

## About the Project

I built this small SOC lab to get hands-on experience with Linux, security monitoring, and incident detection using Wazuh.

The lab runs on my Fedora computer, with Ubuntu Server installed in VMware.

## Technologies Used

- **Fedora Linux** – Main operating system
- **Ubuntu Server** – Virtual machine
- **VMware Workstation** – Virtualization
- **Wazuh SIEM** – Security monitoring and log analysis
- **OpenSSH** – Remote access and authentication testing

## What I've Done

- Installed and configured Ubuntu Server and Wazuh.
- Connected to the server using SSH.
- Simulated failed SSH login attempts.
- Investigated authentication logs using `journalctl`.
- Detected suspicious login activity in Wazuh.

## What I Learned

This project helped me understand how Linux authentication logs are collected and analyzed using a SIEM.

I learned how to investigate failed login attempts, identify important information in security alerts, and use Wazuh to better understand suspicious activity.
